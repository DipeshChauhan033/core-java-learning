# 📘 Core Java Learning

Welcome to **Core Java Learning** — a structured repository focused on mastering **Core Java fundamentals** through hands-on programs, examples, and practice exercises.

This repository is created as a learning reference for students and beginners who want to build a **strong foundation in Java programming** before moving to advanced Java or frameworks.

---

## 🎯 Purpose of This Repository

- Understand **Java fundamentals from scratch**
- Practice **object-oriented programming concepts**
- Learn how Java handles **exceptions, memory, and execution**
- Improve problem-solving skills using Java
- Prepare for **advanced Java, interviews, and real-world projects**

---
